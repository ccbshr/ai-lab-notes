# src/basics —— Python 基础语法练习（Task 07）

来自 PyCharm 工程 `PyCharmMiscProject` 的 9 个练习文件，按原文件名收录。

| 文件 | 主题 | 说明 |
|---|---|---|
| `1.py` | 基本类型与转换 | int/float/str/bool 互转、f-string、真值判断 |
| `2.py` | 条件判断 | if/elif/else，输入成年/身高判断 |
| `3.py` | （空文件） | 占位，暂无内容 |
| `4.py` | 嵌套循环（for） | 九九乘法表，双 for + 格式化输出 |
| `5.py` | 嵌套循环（while） | 九九乘法表，双 while 实现 |
| `6.py` | 列表操作 | append / extend / pop / del / index |
| `7.py` | 字典操作 | 键值读取、f-string 输出 |
| `8.py` | 元组操作 | tuple 转换、len、索引访问 |
| `9.py` | 集合操作 | set 去重特性演示 |

运行环境：Python 3.x（纯标准库，无第三方依赖）。

运行示例：

```bash
cd src/basics
python 4.py
```
